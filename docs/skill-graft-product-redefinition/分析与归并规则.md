# Skill Graft：分析与归并规则

## 1. 目的与证据约定

本规则把“选择一个工作区后，发现其中所有 Skill / Agent 体系”定义成一个只读、可解释、可回滚的产品能力。分析结果服务于中心库初始化、连接工作树、上游变化融合和替换预览；分析阶段不写入被选工作树。

本文件的真实样本是 `E:\ozdqp-main-fix`，核实时间为 2026-08-26。标记约定：

- **实测**：由文件系统、Git 索引、文件哈希或包清单直接得到。
- **推断**：由路径、命名、共同命令或相对文件集合推断出的关系，产品中必须允许用户展开证据并保留“不确定”状态。
- **未验证**：本次只读盘点没有执行的生产行为，不能在 UI 中伪装成已完成。

### 1.1 对象模型

| 对象 | 定义 | 用户可见名称 | 重要边界 |
|---|---|---|---|
| 工作区 | 用户通过 Windows 文件夹选择器选中的目录 | 工作区 | 分析前只读；脏改、私有文件和缓存必须原样保全 |
| 体系 | 能共同解释的一组 Skill、Agent 规则、后端或来源 | 体系 | 一个体系可以有多个宿主投影和多个版本；首次初始化通常只选一个主体系，彼此独立的项目体系保持分开 |
| 投影 | 同一体系在 `.agents`、`.cursor`、`.claude` 等宿主下的落盘形态 | 宿主投影 | 不因目录不同就重复计数 |
| Skill | 一个 `SKILL.md` 及其同目录资源 | Skill | 同名不等于同内容；冲突必须比较 |
| 规则入口 | `AGENTS.md`、`CLAUDE.md` 等对工作区生效的规则 | 规则入口 | 记录路径和作用范围，不当作普通 Skill |
| 版本 | 中心库某次被确认的完整内容快照 | 中心库 v1、v2… | 生成新版本前必须有预览；旧版本可回滚 |
| 来源 | 物理文件、Git index、Junction、PackageCache、lock 声明或备份 | 来源 | 来源证据始终保留，缓存不自动提升为源 |

## 2. 发现流程

### 2.1 根目录扫描

分析器必须从用户选择的工作区根开始，不预设只有几个固定目录。第一轮只读取以下类别：

1. 常见宿主根：`.agents`、`.claude`、`.cursor`、`.codex`。
2. 任意合理名称：`agent_skills`、`agent-skills`、`agents`、`skills`，以及名称中包含 `agent` / `skill` 的候选目录。
3. 规则入口：大小写不敏感匹配 `AGENTS.md`、`AGENTS.override.md`、`CLAUDE.md`、`CLAUDE.override.md`、`CODEX.md` 等，并记录从根到文件的层级范围。
4. 声明来源：`skills-lock.json`、包清单、manifest、配置文件和 Git tree/index。
5. 物理链接：Windows Reparse Point、Junction、符号链接，必须解析目标并同时保留别名路径。
6. 可能的缓存/备份：`Library\PackageCache`、`PackageCache`、`cache`、`caches`、`temp`、`.pytest_cache`、`backup`、`backups`、`local-overlay.pre-hub-*` 等。
7. Git 索引状态：即使文件物理缺失，也要检查 skip-worktree 条目并标记为休眠/隐藏。

扫描输出至少包含：规范化绝对路径、来源类别、宿主、相对路径、文件大小、mtime、内容哈希、Git 状态、链接目标、声明状态和可见性。

### 2.2 身份键与去重顺序

按以下顺序判定，避免把别名、缓存或不同版本错误合并：

1. **路径安全**：确认真实路径不是工作区外的未授权目录；分析只读，不执行脚本、不启动后端、不 attach。
2. **链接归一化**：若是 Junction/符号链接，先以真实目标作为内容身份，再把别名作为来源投影记录。
3. **声明核对**：将 lock/manifest 声明与物理文件、Git index 条目逐一对照；“只声明”不能冒充已物化。
4. **内容指纹**：对候选文件计算 SHA-256。相同路径名但哈希不同，必须进入比较/冲突，而不是覆盖。
5. **相对集合**：比较 Skill 名称、相对目录、入口 frontmatter、调用后端、包版本和规则范围。
6. **关系输出**：只输出“完全重复”“同后端不同投影”“同家族不同版本/镜像”“真正独立”“休眠”“声明未落盘”“缓存/备份”“待用户确认”等可解释关系。

## 8. 默认动作矩阵

| 发现关系 | 默认 UI | 默认动作 | 需要用户确认的动作 |
|---|---|---|---|
| Junction/符号链接 | 一个实体 + 别名来源 | canonicalize 后只计一次 | 改变链接或目标 |
| 完全重复 | 一个 Skill，多个投影标签 | 自动折叠 | 无；仍可展开来源 |
| 同后端不同投影 | 一个体系，多投影和差异数 | 进入比较 | 选择某投影内容 |
| 同家族不同版本 | 一个体系，版本/镜像标签 | 保留两份证据，比较后再选 | 采纳版本、产生新中心库版本 |
| 真正独立体系 | 独立体系卡 | 不与其他体系合并 | 融合、上传、替换 |
| PackageCache/缓存 | 缓存来源 | 默认排除中心库 | 明确选择后才能融合 |
| 备份 | 保全来源 | 只读、不可作为默认源 | 从备份恢复需单独确认 |
| skip-worktree 物理缺失 | 休眠/隐藏 | 只展示，不恢复 | 恢复/物化 |
| lock 声明未落盘 | 声明未落盘 | 警告，不计入活跃内容 | 下载/恢复 |
| 私有 Skill | 私有、未选择 | 保留，不上传/删除/覆盖 | 用户逐项明确选择 |

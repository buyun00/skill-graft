# Skill Graft 项目方案管理原型

入口是同目录下的 `index.html`。这是一个可点击的静态 HTML/CSS/JavaScript 原型，所有版本、分析和融合状态都是浏览器内 fixture，不读写生产 Skill Graft 或用户工作树。

## 打开方式

- 直接用浏览器打开 `index.html`。
- 若浏览器限制本地脚本，在本目录运行：

  ```powershell
  py -m http.server 4173 --bind 127.0.0.1
  ```

  然后打开 `http://127.0.0.1:4173/index.html?scenario=fresh`。

## 可演示流程

- `?scenario=fresh`：首次选择 `E:\ozdqp-skill-hub` → 只读分析 → 确认一个项目方案 → 创建 `OZDQP Unity 项目方案 v1`。
- 原始 `index.html` 首次页面中的“演示：工作区已有更新”按钮：直接进入三页更新流程——查看发生变化的 Skill → GitHub 风格逐文件差异与 AI 处理 → 在默认可编辑的文件区审阅成果；成果页用一个统一 AI 输入框和文件勾选控制再次修改范围，最后确认合并到中心库。
- 首页只承担入口作用：顶部显示当前是否有新修改，下方三个卡片分别直达工作树、中心库和 AI 助手；不再展示项目方案版本、最近活动或原则说明。首页输入 AI 请求后，会直接进入带有用户消息和 AI 回答正文的完整对话页。
- 主导航包含中心库、工作区、AI 助手和默认隐藏的高级诊断。

## 原型边界

- Windows 原生文件夹选择器仅用选择结果模拟，未实现生产 `IFileDialog`。
- 没有真实文件合并、中心库持久化、工作树接管、回滚或 AI 后端。
- 原型不触碰 `E:\ozdqp-main-fix`、Skill Graft 安装态、数据根、服务、计划任务或旧备份。
